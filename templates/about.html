About ShopFlow E-Commerce System

A production-grade, full-stack E-Commerce application architected with Flask, PostgreSQL/SQLite, and Bootstrap 5 to illustrate modern software engineering practices, secure session management, database transactions, and REST APIs.

Technology Stack

Backend Architecture
  • Python Flask: Application factory & Blueprints pattern
  • Flask-SQLAlchemy: Object-Relational Mapping (ORM)
  • Flask-Login: Session management & authentication
  • Werkzeug: Secure salted password hashing (pbkdf2:sha256)
  • Flask-WTF: CSRF protection on forms and state-changing requests
Frontend & UI
  • Bootstrap 5.3: Responsive mobile-first design grid
  • Bootstrap Icons 1.11: Modern icon set
  • Vanilla JavaScript (ES6+): AJAX Add to Cart, dynamic badges & toast notifications
  • Jinja2: Server-side template rendering with custom currency formatting

Core Engineering Features

Database Transactions

Checkout operations run inside an atomic database transaction. If inventory is insufficient or an error occurs, the session rolls back to prevent inconsistent states.

Role-Based Access Control

Enforces strict separation between ordinary customers and administrators. Protected administrative routes reject unauthorized requests with HTTP 403 Forbidden.

RESTful JSON APIs

Complete API endpoints for products, shopping cart, order placement, and tracking with standardized HTTP methods and status codes.
